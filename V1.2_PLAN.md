# Tayyibat v1.2 — post-launch fixes plan

Triaged from real App Store launch reviews. Decisions locked with the user
(2026-07-21). Build on branch `claude/tayyibat-ios-app-ftYsJ`, push, keep CI
green, then bump to **1.2.0+8**.

## Locked decisions
- **Errors:** no specific repros supplied → do a **defensive hardening sweep**
  of every screen (crashes, bad/empty states, network failures, null-safety),
  not a chase of named bugs.
- **Recommendation engine:** return **3 distinct meal options at once** per
  request (not one). Keep it exempt from the daily cap (text task).
- **Pricing:** **keep $6.50**; v1.2 features justify it. No price change.
- **Session:** work proceeds locally (user relaunched Claude Code on the Mac).

## Work items

### 1. Spelling / copy audit (ar + en)
- Sweep `flutter_app/lib/l10n/app_ar.arb` and `app_en.arb` plus data files
  (`data/*.dart`, guidebook, meal banks, tips, program) for typos and awkward
  phrasing. English especially — reviews flag spelling.
- Cross-check ar↔en parity (369 keys each as of v1.1).

### 2. Editable analyzed ingredients (high impact)
- On the result / meal-detail screen, let the user **edit or delete** each
  identified `FoodItem`: correct the name, change the zone (green/yellow/red),
  remove a wrong item.
- **Recompute the overall score client-side** after edits (mirror the server
  scoring: green full, yellow 60%, red 0 + cap 50 if an explicit red item).
- Persist edits back to SQLite; mark `wasEdited` so it's distinguishable.
- Recompute `MealNutrition` totals from surviving items.

### 3. Recommendation engine → 3 options
- Change `SuggestionService.suggestMeal()` and the server `suggest` task to
  return **3 distinct suggestions** (prompt: "suggest 3 different Tayyib meals
  … return a JSON array"). Update `MealSuggestion` model + `SuggestionsScreen`
  to render 3 cards.
- Add "regenerate" and keep it locale-aware.

### 4. Meal-plan tracking
- Persist generated weekly plans (new SQLite table `meal_plans` / `plan_days`),
  let the user mark each day's meals done, and show progress.
- Surface saved plans instead of them vanishing on navigation.

### 5. Editable display name (the "username" complaint)
- There is no username today — the greeting derives from the email prefix.
- Add a **display name** field: collected in onboarding (optional) and editable
  in Settings → Account. Store in SharedPreferences (or a `profile` table).
  Use it for the Today greeting instead of the email prefix.

### 6. Onboarding overhaul
- Roadmap item 10 (name + age, currently skipped). Add a short, friendly
  multi-step onboarding after the disclaimer: welcome → name (optional) →
  optional age → done. Keep it skippable; never gate core use behind it.
- Tighten copy and visual polish (reviews: "poor onboarding").

### 7. Hardening sweep
- Every screen: guard null/empty states, wrap async in try/catch routed
  through `describeError`, confirm `mounted` checks across awaits, empty-list
  placeholders, and image/file load fallbacks.
- Add widget/unit tests for the new score-recompute and 3-suggestion parsing.

## Server changes (deploy after)
- `supabase/functions/analyze/index.ts`: `suggest` task → 3-item array
  (both locales). Deploy: `supabase functions deploy analyze --no-verify-jwt`
  from repo root.

## Release
- pubspec → `1.2.0+8`. Update CLAUDE.md §7 roadmap + release-notes kits
  (ar + en) for App Store and Play. Build IPA + AAB on Mac.

## Not in scope / user's call
- Price change (App Store Connect) — decided to keep $6.50.
- The Android 12-tester closed-test clock (separate track, unaffected).
